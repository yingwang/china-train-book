# 中国高铁游指南

杭州出发 · 不自驾 · 舒适优先 · 优先万豪旅享家（Marriott Bonvoy）体系。

## 目的地体例规范

全书所有目的地均统一依循结构化标准深度展开：

1. **高铁与抵离**：班次密度、最优车次、座席舒适度建议与抵离车站选择。
2. **万豪旅享家酒店精选**：涵盖地理区位、客群定位、价格区间、硬件特色与餐饮酒廊评测。
3. **在地风尚特色居停**：甄选兼具深厚历史底蕴或卓越设计美学的代表性独立酒店。
4. **模块化行程规划**：提供半日至三日的从容游赏节奏方案。
5. **核心胜迹深度品鉴**：解析历史文脉、建筑与艺术看点、最佳参访时段与参访须知。
6. **地道寻味**：探寻契合文人风雅与地域特色的地道风味饮食。
7. **最佳出行窗口**：综合气候温湿度与自然物候的精选出行时节。
